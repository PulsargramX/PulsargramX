# Pulsargram X

A fork of Telegram X, with some major features ported over from the mainline Telegram client, such as:

- Forum topics
- Web apps
- Rich messages
- Quotes
- Ability to select parts of the message
- Boosts
- Contact notes
- Custom contact profile pics/profile pic suggestions
- Member tags

And many more useful features sprinkled in.

100% vibe coded, mostly with GPT models.
